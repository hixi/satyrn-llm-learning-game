# Wave 0 — Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Lit/DOM shell with a full-Phaser shell (boot, theme, UI factory, HUD, title/prologue, map, dialogue, journal, toasts, act cards) plus state v2, star-threshold content validation, and a deterministic e2e harness — with a world placeholder so every route works before Wave 1.

**Architecture:** Pure logic stays Phaser-free and unit-tested (`store/`, `game/ui/focus.ts`, `game/layout.ts`, `game/worlds/*/logic.ts`, `tools/`); Phaser scenes are thin renderers over those modules. Persistent HUD overlay never unmounts, so the mode toggle works from inside a world.

**Tech Stack:** Phaser `^3.80.0` via npm, TypeScript strict, Vite, Vitest + jsdom, Playwright. No Lit, no external art/audio/font assets.

**Spec:** `docs/superpowers/specs/2026-10-02-phaser-rebuild-design.md` (Wave 0 row + §§6–8,10–13; prologue as amended to 3 ungated screens).

## Global Constraints

- Phaser `^3.80.0`, bundled by existing Vite setup; `base: './'` unchanged.
- `Scale.RESIZE` canvas filling the viewport; layout re-flows on resize.
- Hash routes only: `#/` (map), `#/world/<id>`, `#/journal` (overlay); legacy `#/thread` lands on the map in Thread mode.
- No Lit imports, no HTML game chrome, no `<a>` navigation anywhere in game UI.
- No external art, audio, or font assets — textures drawn in code, SFX via WebAudio oscillators.
- `settings.soundOn` defaults to `false` and persists; first toggle-on plays a confirmation blip; no music in v1.
- Every interactive target ≥ 48 CSS px; DPR capped at 2; particle counts scaled down on small screens.
- `CURRENT_STATE_VERSION = 2`; storage key stays `'satyrn-book-as-game:v1'` so v1 saves migrate.
- Star thresholds: non-negative integers with `three <= two`; every mechanic except `mechanic.commons-garden` requires them; garden must not have them.
- Screen-reader narration via visually-hidden `#satyrn-live` aria-live region; canvas carries one role/label.
- `window.__satyrn` debug hook exists only when the URL has `?e2e=1`.
- `npm run check` (content → typecheck → unit → build → e2e) is green at every task commit.

## Review Focus

- A corrupt localStorage value or a v1 save → game boots with fresh/migrated state, never a crash (Task 1 test).
- An unknown hash like `#/nope` → in-canvas not-found card with a working "Back to the map" button (Task 6 e2e).
- A portrait phone viewport (390×844) → compact layout, board fits without scrolling, targets ≥ 48px (Task 3 unit + Task 11 e2e).
- Keyboard-only play: Tab reaches every button, Enter activates, Esc backs out of overlay/world (Task 7 unit + Task 11 e2e).
- Sound stays off by default and the toggle persists across reload (Task 4 test + Task 11 e2e).
